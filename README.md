# Verification Badge — Holographic Artifact Study

An interactive prototype exploring holographic security-label design directions.
This is design exploration for executive review, **not** a production authentication system.

## View it

**Live link:** https://alisonhu-magic.github.io/verification-badge/

It's a single self-contained HTML file (fonts, patterns, and logo are embedded), so it also works offline — just open `index.html` in any modern browser.

## How to interact

- **Hover** a label to see the holographic reflection and light shift.
- **Click** a label to focus / enlarge it.
- The right-hand **controls panel** adjusts: hologram intensity, saturation, reflection size, pattern density, **pattern opacity**, perspective tilt, cursor-interaction style, freeze-light, and all printed text including the **circular ring text**.
- **Generate component** exports the selected direction as a self-contained React component.

## Feedback that helps

- Which design direction feels most premium / on-brand?
- Does the holographic effect read as a *security artifact* rather than decorative?
- Any wording / branding changes (wordmark, cobrand, ring text).

## Updating

Edit `index.html` and push to `main`; GitHub Pages redeploys automatically (usually within a minute).
